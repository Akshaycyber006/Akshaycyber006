# Akshay's Pixel-Art GitHub Portfolio

## Run locally (Windows)
1. Install Python 3 if it is not already installed.
2. Extract this folder.
3. Open Command Prompt inside this folder.
4. Run: `python run.py`
5. Open `http://localhost:8000` in your browser.

The contribution animation requests the public GitHub contribution calendar for `Akshaycyber006`. Internet access is required. It does not create fake commits or modify your GitHub history.

The QR code in `assets/qrverse-real-qr.png` is a real QR code linking to:
https://github.com/Akshaycyber006/QRVerse
